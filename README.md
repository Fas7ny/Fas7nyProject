# Fas7ny Tourism Web & Mobile App

## Overview
**Fas7ny** is a comprehensive tourism platform designed to showcase the beauty and attractions of Egypt. It consists of both a **Web Application** and a **Mobile App**, providing tourists with an intuitive and seamless experience to explore tourist places, activities, hotels, restaurants, and trips.

---

## Features

### Web Application
- **Tourist Places & Activities:** Browse popular tourist destinations and activities across Egypt.  
- **Hotels & Restaurants:** Search, filter, and view detailed information.  
- **Trips & Packages:** Explore curated trips and tourism packages.  
- **User Authentication:** Secure registration, login, and profile management using ASP.NET Identity.  
- **Admin Panel:** CRUD operations for all entities with easy management.  
- **Responsive Design:** Works across desktops, tablets, and mobile browsers.

### Mobile App
- **Cross-Platform:** Available for iOS and Android.  
- **Real-Time Updates:** Syncs with the web backend.  
- **User-Friendly Interface:** Easy navigation and quick access to attractions.  
- **Push Notifications:** Stay updated with the latest offers and events.  
- **Offline Support:** Basic offline access for saved places and trips.
